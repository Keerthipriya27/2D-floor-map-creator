# 🗺️ 2D Floor Map Creator

An interactive web-based tool that allows users to design digital floor maps by drawing rooms, corridors, and navigation elements on top of an uploaded floor plan image.

🌐 **Live Website:**  
https://keerthipriya27.github.io/2D-floor-map-creator/

---

## 🚀 Features

- 📤 Upload a floor plan image as background  
- 🏫 Draw different room types:
  - Classrooms
  - Labs
  - Staff Rooms
  - Seminar Halls
  - Washrooms
  - Offices and more  
- 🎨 Automatic color coding for each room type  
- 📍 Add navigation markers and labels  
- 🔍 Zoom and grid alignment  
- ↩ Undo / Redo support  
- 💾 Export floor map as:
  - PNG image
  - JSON data (for indoor navigation systems)

---

## 💡 Use Case

This tool is useful for:

- Indoor navigation projects  
- College / school campus mapping  
- Smart building systems  
- Emergency exit planning  
- Facility management  

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript  
- Canvas API  
- GitHub Pages (for deployment)

---

## 🎯 How to Use

1. Open the live website  
2. Upload a floor plan image  
3. Select a room type  
4. Draw rooms on top of the layout  
5. Add labels and navigation points  
6. Export the final map
